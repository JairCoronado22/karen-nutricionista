# Página web de Karen Coronado

Landing page responsive para Karen Coronado, nutricionista pediátrica.

## Estructura

- `index.html`: contenido principal.
- `css/styles.css`: diseño y ajustes responsive.
- `js/main.js`: cambio de paleta, menú móvil, animaciones y copiado de datos.
- `assets/`: fotografías, versiones WebP y favicon.
- `netlify.toml`: configuración para Netlify.

## Ajustes finales incluidos

- Sección **Agenda una consulta** adaptada a celulares, incluyendo el correo largo.
- Tarjetas de WhatsApp, teléfono y correo sin desbordamiento horizontal.
- Icono de **Formas de pago** cuadrado en pantallas pequeñas.
- Datos bancarios con ajuste de línea en móviles.

Para probar localmente, abre la carpeta con Live Server. Para publicar en Netlify, sube esta carpeta o arrastra el archivo ZIP en Netlify Drop.
